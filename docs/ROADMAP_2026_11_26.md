# Roadmap — semantic substrate + failed-benchmark repair (2026-11-26)

## Standing rule (corrected)

The earlier roadmap said “everything below is a new benchmark, not a
RAVANA-LEARN-5 repair.” That was too narrow. The active instruction is:

> Work the failed benchmarks even if that requires adding a new system.
> Research the brain, test in scratch first, and implement only what fixes a
> measured gap. Do not change a gate, threshold, or rubric to manufacture a
> verdict.

So this roadmap has two tracks that run in parallel:

1. **A — Repair the failed benchmarks** (CAR, WFA, RSI, TRA).
2. **B — Finish the declared new benchmark TRA-K** (explicit semantic type
   channel) and report it honestly, without letting it substitute for A.

No fake-oracle `1.00` is capability evidence. No saturated endpoint is a
progress signal unless its mutation control moves. No production mechanism is
implemented until a scratch experiment fixes the measured gap.

## Decision rules

1. Scratch first; production only if the experiment fixes the measured gap.
2. Research the brain when a design choice is unsettled; cite the source.
3. Never change a gate or threshold to obtain a verdict.
4. Fake arm validates the instrument only; it never proves capability.
5. Report PASS / FAIL / instrument-invalid / unmeasured honestly.
6. Update this roadmap after every material change.
